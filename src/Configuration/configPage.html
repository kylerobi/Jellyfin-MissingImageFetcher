Missing Primary Images

Finds items with no Primary image (poster / thumbnail) and asks your enabled image providers to fetch one. Existing images and metadata are never replaced. Run it from Dashboard → Scheduled Tasks → Library → Fetch Missing Primary Images.

Item types to check

Behaviour

Helps items with no TMDb/TVDb ID, because image providers need one to find artwork. Existing metadata is kept.
Check the server log afterwards to see the list.
0 = retry every run.
0 = no limit. The rest are picked up on the next run.
Avoids hammering TMDb, TVDb and other providers.
